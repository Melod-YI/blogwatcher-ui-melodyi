# Pitfalls Research: Article Notes 功能

**研究日期:** 2026-05-07
**里程碑:** v1.4 Article Notes

## 常见陷阱

### 文件存储相关

| 陷阱 | 预防策略 |
|---|---|
| 文件与数据库状态不一致 | 写入/删除备注时同步更新 has_note 字段 |
| 删除文章后备注文件残留 | 需要在删除文章时检查并删除对应备注文件 |
| notes 目录不存在 | 初始化时创建目录，或首次写入时自动创建 |

### CLI 相关

| 陷阱 | 预防策略 |
|---|---|
| 文章不存在时写入备注 | 先查询文章存在，再写入备注 |
| 源文件不存在时报错 | 读取文件前检查文件存在，明确报错消息 |
| 源文件过大 | 考虑限制文件大小（如 1MB） |

### Markdown 渲染相关

| 陷阱 | 预防策略 |
|---|---|
| XSS 注入（恶意 HTML） | 配置 Goldmark 禁用 unsafe HTML |
| 超长内容渲染性能 | 考虑内容大小限制 |

### UI 相关

| 陷阱 | 预防策略 |
|---|---|
| 备注按钮误触发 | 按钮设计明显区分，使用图标或标签 |
| has_note 字段未同步查询 | 文章列表查询需 JOIN 或额外查询备注状态 |

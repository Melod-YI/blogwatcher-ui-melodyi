# Phase 14: CLI Filtering Enhancement - Plan 01

**Objective:** 为 article list 命令添加 `--not-noted` 筛选参数，允许用户筛选无备注文章。

## Scope

- 在 `ListFilterOptions` 结构体添加 `HasNote` 字段
- 在 `ListArticlesWithFilters` 方法添加 `has_note = FALSE` 筛选条件
- 在 CLI `article list` 命令添加 `--not-noted` flag
- 确保 `--not-noted` 与现有筛选参数（`--unread`, `--blog`, `--after`）可组合使用

## Truths

- Phase 13 已完成：`articles` 表有 `has_note` 字段，`Article.HasNote` 和 `ArticleWithBlog.HasNote` 已存在
- `scanArticleWithBlog` 已包含 `has_note` 字段扫描
- `--unread` 和 `--read` 是互斥的（已通过 `MarkFlagsMutuallyExclusive` 实现）
- `--not-noted` 是独立筛选参数，可与任何其他参数组合

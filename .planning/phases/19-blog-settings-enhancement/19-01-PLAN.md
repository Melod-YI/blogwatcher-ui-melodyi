在 blog-display-row.gohtml 的 `<h3 class="blog-settings-name">` 和 `<div class="blog-settings-meta">` 之间添加两列 URL 显示区域（per D-01）。

**具体实现：**

1. 在 line 4（`<h3 class="blog-settings-name">{{.Blog.Name}}</h3>`）后添加新的 `<div class="blog-settings-url-row">` 容器

2. 容器内部使用 flex 布局，左侧显示 Blog URL，右侧显示 Feed URL：
   ```html
   <div class="blog-settings-url-row">
       <div class="blog-url-column">
           <span class="url-label">Blog URL</span>
           <a href="{{.Blog.URL}}" target="_blank" rel="noopener noreferrer"
              class="blog-settings-url">{{.Blog.URL}}</a>
       </div>
       <div class="blog-url-column">
           <span class="url-label">Feed URL</span>
           <a href="{{.Blog.FeedURL}}" target="_blank" rel="noopener noreferrer"
              class="blog-settings-url">{{if .Blog.FeedURL}}{{.Blog.FeedURL}}{{else}}—{{end}}</a>
       </div>
   </div>
   ```

3. Feed URL 为空时显示 "—" 占位符（per D-03a 空值允许）

4. 保持现有的 URL 链接样式（target="_blank", rel="noopener noreferrer" per D-01a）

**关键布局要求（per D-01）：**
- 两列并排显示（flex layout）
- 左侧：Blog URL，右侧：Feed URL
- gap: 24px 或适当间距
- URL 标签使用小字体（如 12px 或 13px）
- URL 文字截断处理（overflow: hidden, text-overflow: ellipsis）
</action>

<action>
在 styles.css 的 `.blog-settings-card` 相关样式区域后添加两列 URL 布局样式（per D-01）。

**具体样式规则：**

```css
/* Blog Settings URL Row - 两列并排显示 */
.blog-settings-url-row {
    display: flex;
    gap: 24px;
    margin-bottom: 8px;
}

.blog-url-column {
    flex: 1;
    min-width: 0; /* 允许文字截断 */
}

.url-label {
    display: block;
    font-size: 13px;
    color: var(--text-secondary);
    margin-bottom: 2px;
}

.blog-settings-url {
    display: block;
    font-size: 14px;
    color: var(--text-link);
    text-decoration: none;
    overflow: hidden;
    text-overflow: ellipsis;
    white-space: nowrap;
}

.blog-settings-url:hover {
    text-decoration: underline;
}
```

**关键样式要求（per D-01）：**
- 两列 flex 布局，gap 24px
- URL 标签小字体（13px），次要文字颜色
- URL 文字截断处理（防止长 URL 破坏布局）
- hover 状态添加 underline（保持现有链接交互）
</action>

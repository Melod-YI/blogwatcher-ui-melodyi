   <div class="blog-edit-url">

<action>
在 styles.css 的 `.blog-edit-form` 相关样式区域后添加 URL 输入框和错误提示样式（per D-03）。

**具体样式规则：**

```css
/* Blog Edit URL Input - URL 输入框样式 */
.blog-edit-url,
.blog-edit-feed-url {
    margin-bottom: 16px;
}

.edit-label {
    display: block;
    font-size: 13px;
    color: var(--text-secondary);
    margin-bottom: 4px;
}

.blog-edit-url input,
.blog-edit-feed-url input {
    width: 100%;
    padding: 8px 12px;
    border: 1px solid var(--border-color);
    border-radius: 4px;
    font-size: 14px;
    background: var(--input-bg);
    color: var(--text-primary);
}

.blog-edit-url input:focus,
.blog-edit-feed-url input:focus {
    border-color: var(--accent-color);
    outline: none;
}

/* URL Validation - 错误提示样式 */
.blog-edit-url input:invalid,
.blog-edit-feed-url input:invalid {
    border-color: var(--danger);
}

.error-message {
    display: none; /* 默认隐藏 */
    color: var(--danger);
    font-size: 13px;
    margin-top: 4px;
}

.blog-edit-url input:invalid + .error-message,
.blog-edit-feed-url input:invalid + .error-message {
    display: block; /* 验证失败时显示 */
}
```

**关键样式要求（per D-03）：**
- 错误提示默认隐藏（display: none）
- 输入框 invalid 状态显示红色边框（border-color: var(--danger))
- 输入框 invalid 时错误提示显示（:invalid + .error-message）
- 错误提示红色文字（color: var(--danger))
- 错误提示字体大小 13px，margin-top 4px
</action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI → Database | 本地数据库读写 |
| CLI → Scanner → Network | RSS/Atom feed 获取，需要网络访问 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Tampering | scanner.ScanAllBlogs | accept | RSS feed 来源不可信，scanner 包已处理解析错误 |
| T-12-05 | Denial of Service | network timeout | mitigate | scanner 包使用 context timeout，CLI 应传递 context |
| T-12-06 | Information Disclosure | scan output | accept | 输出博客名称和文章数，无敏感信息 |

</threat_model>

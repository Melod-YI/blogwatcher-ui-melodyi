| Boundary | Description |

| CLI → Database | 本地数据库文件读写，无网络边界 |
| CLI → Filesystem | 本地文件访问（数据库路径），用户可控 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-12-02 | Information Disclosure | serve command | accept | 本地服务，端口可通过环境变量配置，无敏感信息暴露 |
| T-12-03 | Elevation of Privilege | go install | accept | 标准工具链，用户主动安装，无特权操作 |

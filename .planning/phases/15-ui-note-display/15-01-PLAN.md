         ```go

           "github.com/yuin/goldmark"
           "github.com/yuin/goldmark/extension"
           "github.com/yuin/goldmark/renderer/html"
         )
         ```
       
       - 在 FuncMap 中添加 renderMarkdown 函数：
         ```go
         funcMap := template.FuncMap{
           "timeAgo":    timeAgo,
           "faviconURL": faviconURL,
           "smryURL":    smryURL,
           "renderMarkdown": func(content string) template.HTML {
             // 创建 goldmark 实例 with GFM extensions
             md := goldmark.New(
               goldmark.WithExtensions(
                 extension.GFM,
               ),
               goldmark.WithRendererOptions(
                 html.WithHardWraps(),
                 html.WithXHTML(),
               ),
             )
             
             var buf bytes.Buffer
             if err := md.Convert([]byte(content), &buf); err != nil {
               // 错误时返回原始文本
               return template.HTML(content)
             }
             return template.HTML(buf.String())
           },
         }
         ```

    注意：renderMarkdown 返回 template.HTML 以避免 HTML 被自动转义。
    GFM 扩展自动启用：Tables, Strikethrough, TaskLists, Autolinks。

            return
        }

        // Read note content from file
        homeDir, err := os.UserHomeDir()

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Tampering | handleNote | mitigate | 验证 article ID 为有效数字（strconv.ParseInt 失败返回 400），防止路径遍历攻击 |

    1. **定义 CategoryWithBlogCount struct**（在 BlogWithCount 附近）：
       ```go
       // CategoryWithBlogCount extends Category with blog count for display.
       type CategoryWithBlogCount struct {

       }
       ```

    2. **CreateCategory(name string)**：
       - SQL: `INSERT INTO categories (name, created_at) VALUES (?, ?)`
       - 返回新创建的 Category（ID 从 result.LastInsertId 获取）
       - created_at 使用 time.Now()
       - 验证 name 不为空（如果空则返回 error）

    3. **ListCategoriesWithBlogCount()**：
       - SQL 使用 LEFT JOIN：
         ```sql
         SELECT c.id, c.name, c.created_at, COUNT(b.id) as blog_count
         FROM categories c
         LEFT JOIN blogs b ON b.category_id = c.id
         GROUP BY c.id
         ORDER BY c.name
         ```
       - 返回 []CategoryWithBlogCount
       - 未分类的 blog 不在此列表中（它们没有 category_id）

    4. **UpdateCategoryName(id int64, name string)**：
       - SQL: `UPDATE categories SET name = ? WHERE id = ?`
       - 验证 name 不为空
       - 返回 error（包括 category 不存在的情况）

    5. **DeleteCategory(id int64)** - 使用事务确保原子性：
       ```go
       func (db *Database) DeleteCategory(id int64) error {
           tx, err := db.conn.Begin()
           if err != nil {
               return err
           }
           defer tx.Rollback()

           // 1. 置空关联 blog 的 category_id
           _, err = tx.Exec(`UPDATE blogs SET category_id = NULL WHERE category_id = ?`, id)
           if err != nil {
               return err
           }

           // 2. 删除分类
           _, err = tx.Exec(`DELETE FROM categories WHERE id = ?`, id)
           if err != nil {
               return err
           }

           return tx.Commit()
       }
       ```

    6. **UpdateBlogCategory(blogID int64, categoryID *int64)**：
       - SQL: `UPDATE blogs SET category_id = ? WHERE id = ?`
       - categoryID 为 nil 时传入 NULL
       - 使用 sql.NullInt64 处理 nullable 值：
         ```go
         var catID sql.NullInt64
         if categoryID != nil {
             catID = sql.NullInt64{Int64: *categoryID, Valid: true}
         }
         _, err := db.conn.Exec(`UPDATE blogs SET category_id = ? WHERE id = ?`, catID, blogID)
         ```

    **代码风格要求:**
    - 方法签名遵循现有 pattern（如 UpdateBlogName, DeleteBlogWithArticles）
    - 使用 db.conn.Exec 或 db.conn.Query
    - 事务使用 tx.Begin() + defer tx.Rollback() + tx.Commit() pattern
    - 添加日志注释说明方法用途

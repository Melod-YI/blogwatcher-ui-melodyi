**方法签名变更：**

- 改为：`func (db *Database) AddArticlesBulk(articles []model.Article) (inserted int, skipped int, error error)`

**SQL 语句变更：**
- 当前：`INSERT INTO articles (blog_id, title, url, thumbnail_url, published_date, discovered_date, is_read) VALUES (?, ?, ?, ?, ?, ?, ?)`
- 改为：`INSERT OR IGNORE INTO articles (blog_id, title, url, thumbnail_url, published_date, discovered_date, is_read) VALUES (?, ?, ?, ?, ?, ?, ?)`

**返回值计算：**
- 每个INSERT成功：inserted++
- 每个INSERT被忽略（重复URL）：skipped++
- 使用 result.RowsAffected() 检测是否成功插入（1 = inserted, 0 = skipped）

**实现逻辑：**
```go
func (db *Database) AddArticlesBulk(articles []model.Article) (inserted int, skipped int, error error) {
    if len(articles) == 0 {
        return 0, 0, nil
    }
    tx, err := db.conn.Begin()
    if err != nil {
        return 0, 0, err
    }
    stmt, err := tx.Prepare(`INSERT OR IGNORE INTO articles (blog_id, title, url, thumbnail_url, published_date, discovered_date, is_read) VALUES (?, ?, ?, ?, ?, ?, ?)`)
    if err != nil {
        _ = tx.Rollback()
        return 0, 0, err
    }
    defer stmt.Close()

    for _, article := range articles {
        result, err := stmt.Exec(
            article.BlogID,
            article.Title,
            article.URL,
            nullIfEmpty(article.ThumbnailURL),
            formatTimePtr(article.PublishedDate),
            formatTimePtr(article.DiscoveredDate),
            article.IsRead,
        )
        if err != nil {
            _ = tx.Rollback()
            return inserted, skipped, err
        }
        rowsAffected, _ := result.RowsAffected()
        if rowsAffected == 1 {
            inserted++
        } else {
            skipped++
        }
    }
    if err := tx.Commit(); err != nil {
        return inserted, skipped, err
    }
    return inserted, skipped, nil
}
```

注意：INSERT OR IGNORE 遇到 UNIQUE constraint violation（重复URL）时静默跳过，不报错。

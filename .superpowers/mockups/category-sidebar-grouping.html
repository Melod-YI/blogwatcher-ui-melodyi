🎯 Phase 18 UI 设计讨论点

1. 未分类 Blog 位置

  • 方案 A: 顶层，无标签（极简）
  • 方案 B: 顶层，有"未分类"标签
  • 方案 C: 分类之后，分隔线区分
  • 考虑: 用户习惯（先看分类还是先看未分类）

2. 分类标题样式

  • 方案 A: 小字体 + chevron，hover 高亮
  • 方案 B: 背景块 + 计数徽章（蓝色 badge）
  • 方案 C: 背景色 + 右侧计数（灰色）
  • 点击整个标题区域展开/折叠

3. 展开/折叠交互

  • 统一: 所有方案使用 chevron 旋转动画
  • 动画: 250ms ease，流畅自然
  • 持久化: localStorage 记住展开状态
  • 默认: 全部展开（用户可见所有 blog）

4. 空分类显示

  • 方案 A: 完全隐藏（不显示空分类）
  • 方案 B: 显示但 faded + badge "0"
  • 考虑: 用户可能想知道分类存在但无 blog

5. Blog 项样式

  • 继承现有 blog-item 类（hover 背景 + active 高亮）
  • 方案 A/C: 简洁链接样式
  • 方案 B: 有分隔线，更明显的分组边界

6. 主题适配

  • 点击右上角 "切换主题" 测试 Light/Dark
  • 所有方案都使用 CSS custom properties
  • 与现有 sidebar.gohtml 风格一致
